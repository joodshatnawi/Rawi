# Rawi AI — Story Generation Data

## Purpose

This file is the human-readable version of `facts.json`.

It documents the landmark data used by Rawi AI for **story generation**.

The story-generation function currently uses these fields from each landmark:

- `name` → the landmark name in the selected language.
- `welcome` → the language-specific welcome message.
- `story_facts` → the factual content given to the story-generation prompt.

The remaining fields (`location`, `info`, `fun_facts`, and `eras`) are also preserved here because they exist in the original JSON dataset, but they are not directly used by the `generate_story()` function shown in the current code.

> **Important:** This file is for Story Generation. It is separate from `kno.md`, which is used by the RAG system for answering user questions.

# How the Story Generator Uses This Data

The current story-generation function follows this basic flow:

```text
detected_class
      ↓
facts[detected_class]
      ↓
name[language]
welcome[language]
story_facts
      ↓
facts_text
      ↓
Story Generation Prompt
      ↓
Generated Story
      ↓
TTS
```

### Important distinction

- `story_facts.md` / `facts.json` → **Story Generation**
- `kno.md` → **RAG Question Answering**
- `story_generation.md` → **Prompt used to generate the story**
- `query_rewriting.md` → **Prompt used to rewrite user questions before RAG**
- `answer_generation.md` → **Prompt used to generate the final RAG answer**

The original `facts.json` should be kept as the machine-readable version used by the application. This Markdown file is intended to make the dataset easier for engineers and team members to read and understand.
